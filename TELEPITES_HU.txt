CHERRIFT PRE-BETA / GM / WORLD 2 JAVÍTÁS — TELEPÍTÉS
=====================================================

Alap: a GitHub main ág 078a4b58bc0a3b9bab7b9db3d676f7e65543234e commitja.

1. Másold a ZIP-ben található gm, src, supabase és tools mappákat a repository
   gyökerébe. A mappaszerkezetet tartsd meg, a meglévő fájlokat írd felül.

2. A Supabase SQL Editorban egyszer futtasd le ezt a migrációt:

   supabase/migrations/20260809_prebeta_mail_and_gm_titles.sql

   A migráció a régi globális leveleket biztonságosan „jelenlegi fiókok”
   típusra alakítja. Emiatt a korábban elküldött globális leveleket egy később
   létrehozott új account már nem tudja listázni vagy átvenni.

3. A migráció után telepítsd újra a két Edge Functiont:

   supabase functions deploy gm-api
   supabase functions deploy player-api

4. Commit + push után a böngészőben végezz teljes frissítést
   (Ctrl+F5), hogy a GM Tool Pack v1.2 biztosan betöltődjön.
