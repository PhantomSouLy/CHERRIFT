CHERRIFT – PRE-BETA EVENT / GM PROFILE / WORLD 2 JAVÍTÁS
========================================================

Ez a ZIP kizárólag az új vagy módosított fájlokat tartalmazza.
A mappaszerkezetet megtartva másold őket a repository gyökerébe.

KÖTELEZŐ TELEPÍTÉSI SORREND
---------------------------
1. Másold be a ZIP webes fájljait a repository azonos útvonalaira.
2. Futtasd le Supabase-en ezt az új migrációt:
   supabase/migrations/20260809_profile_bundle_revision.sql
3. Deployold újra a GM API Edge Functiont:
   supabase/functions/gm-api/index.ts
4. Commit/push után várd meg a GitHub Pages deployt.
5. A böngészőben végezz hard refresht / ürítsd a webhely cache-ét.

FONTOS
------
- A GM Profile Editor tartós javítása csak az SQL migráció ÉS a friss gm-api
  Edge Function telepítése után működik.
- Az új Event Hub a Lobby gyorsgombjai közül nyílik meg. A régi event panel
  el van rejtve, a régi event útvonal is az új Event Hubra irányít.
- A GM title csak akkor ad teljes skin/world hozzáférést, amikor aktív title.
  Levételkor a title felvétele előtti, ténylegesen megszerzett állapot áll vissza.

FŐ JAVÍTÁSOK
------------
- Atomikus GM Profile Editor mentés és szerveres save-revízió.
- Nyitva maradt régi játékfül nem írhatja felül a frissebb GM módosítást.
- Ideiglenes GM skin/world hozzáférés mindhárom GM title-höz.
- World 2 objektum-culling, csökkentett firefly mennyiség és gyorsítótárazott glow.
- Stabil, elkülönített desktop currency / energy / profile fejléc.
- Külön Event Hub, 7 napos login event, napi progress/jutalmak és Event Shop.
- A régi Closed Beta event felület megszüntetése a használható útvonalakról.
