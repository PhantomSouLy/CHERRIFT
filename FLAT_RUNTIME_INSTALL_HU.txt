CHERRIFT CLEAN RUNTIME 1.3 – TELEFONBARÁT FÁJLHELYEK

MÁSOLÁS:
1. Másold a ZIP teljes tartalmát a CHERRIFT repository gyökerébe.
2. Engedélyezd az index.html és a tools fájlok felülírását.
3. Az új aktív fájlok:
   - src/cherrift_app.js
   - assets/cherrift_app.css
   - src/cherrift_manifest.json
4. Commitold a változásokat, majd várd meg a GitHub Pages frissülését.
5. Telefonon egyszer töröld a webhely gyorsítótárát vagy végezz kemény frissítést.

SIKERES TESZT UTÁN TÖRÖLHETŐ:
- src/runtime/cherrift_app.js
- src/runtime/runtime_manifest.json
- assets/runtime/cherrift_app.css

Ha a src/runtime és assets/runtime mappák ezután üresek, maguk az üres mappák is eltávolíthatók.

FONTOS:
- A csomag tartalmazza a korábbi 1.2 Wuxia Sakura és World 2 RGBA javítást is.
- A későbbi általános frissítéseknél jellemzően csak ezt a három fájlt kell kezelni:
  index.html, src/cherrift_app.js, assets/cherrift_app.css
